# GameplayEvent Payload 类型化

## 目标

按原始设计文档（`module six`）补全 `GameplayEventFrame` / `GameplayEventBus` 的类型化 payload 支持，使 `AttributeChangedEvent` 等携带任意数据的事件能发布和消费。

## 当前状态 vs 目标

```
当前：只有 GameplayEventRecord（固定字段 EventId + Source + Target + Magnitude + PayloadIndex）
      PayloadIndex 字段存在但从未填充

目标：每种 [GameplayEvent] 有独立的 payload 缓冲
      GameplayEventRecord.PayloadIndex → 指向同帧 payload 缓冲的索引
      消费者通过 PayloadIndex 读取完整 payload
```

## 设计决策

### 事件 struct 即 Payload

不做"空标记 struct + 独立 Payload struct"的分层。声明即定义：

```csharp
[GameplayEvent(Tag = "Event.Damage")]
public partial struct DamageEvent
{
    public float Amount;
    public Entity Source;
    public Entity Target;
}

[GameplayEvent(Tag = "Event.Attribute")]
public partial struct AttributeChangedEvent
{
    public Entity Target;
    public GameplayAttribute Attribute;
    public float OldValue;
    public float NewValue;
}
```

SG 扫描这些 struct，生成：
- `EGameplayEventKind` enum（已有）
- `GameplayEventRegistry` Tags（已有）
- **`GameplayEventFrame` partial** —— 每种 event 一个 `StructBuffer<T>`
- **`GameplayEventBus` partial** —— 每种 event 一个 `EnqueueXxx` 方法

### Handler 读取 payload 的方式

不改 `IGameplayEventHandler` 接口签名。Handler 通过 `record.PayloadIndex` 自行读取：

```csharp
// 新增：GameplayEventFrame 上的通用读取方法
public ref T GetPayload<T>(int index) where T : struct
{
    // SG 生成 switch(EGameplayEventKind) → 转发到对应 buffer
}
```

或直接通过 SG 生成的辅助：

```csharp
// SG 生成：
public ref GameplayEventFrame GetDamagePayload(int index)
    => ref DamagePayloads.buffer[index];

// Handler 中：
ref var payload = ref frame.GetDamagePayload(record.PayloadIndex);
```

优先用后者——零开销，不需要 switch/TryGet，编译期绑定类型。

### Tick 顺序

```text
Phase 0  GameplayEventDispatcher.Tick() —— 消费上一帧事件
Phase 1  Task Systems
Phase 2  AbilityTaskSystem
Phase 3  EffectSystem —— Apply / Remove，通过 Manager 修改 Aggregator
Phase 4  AttributeAggregatorManager.Flush() —— 发布 AttributeChangedEvent 到 pending 帧
Phase 5  ProcessPendingDeletions

下一帧 Phase 0：AttributeChangedEvent 被分发
```

与设计一致：属性变化事件在固定 Flush 阶段生产，下一帧消费。

## 生成代码

### SG 输入

```csharp
[GameplayEvent(Tag = "Event.Damage")]
public partial struct DamageEvent
{
    public float Amount;
    public Entity Source;
    public Entity Target;
}

[GameplayEvent(Tag = "Event.Attribute")]
public partial struct AttributeChangedEvent
{
    public Entity Target;
    public GameplayAttribute Attribute;
    public float OldValue;
    public float NewValue;
}
```

### SG 输出 1：GameplayEventFrame.Payloads.g.cs

```csharp
// <auto-generated />
namespace Gameplay.Abilities;

public sealed partial class GameplayEventFrame
{
    public readonly StructBuffer<DamageEvent> DamageEvents = new();
    public readonly StructBuffer<AttributeChangedEvent> AttributeChangedEvents = new();

    public void Reset()
    {
        DamageEvents.Reset();
        AttributeChangedEvents.Reset();
    }
}
```

### SG 输出 2：GameplayEventBus.Enqueue.g.cs

```csharp
// <auto-generated />
namespace Gameplay.Abilities;

public sealed partial class GameplayEventBus
{
    public void Enqueue(in DamageEvent payload, Entity source, Entity target)
    {
        int index = pending.DamageEvents.Add(payload);
        pending.Records.Add(new GameplayEventRecord
        {
            EventId      = (ushort)EGameplayEventKind.Damage,
            Source       = source,
            Target       = target,
            Magnitude    = 0f,
            PayloadIndex = index,
        });
    }

    public void Enqueue(in AttributeChangedEvent payload)
    {
        int index = pending.AttributeChangedEvents.Add(payload);
        pending.Records.Add(new GameplayEventRecord
        {
            EventId      = (ushort)EGameplayEventKind.Attribute,
            Source       = default,
            Target       = payload.Target,
            Magnitude    = 0f,
            PayloadIndex = index,
        });
    }
}
```

> `EnqueueXxx` 参数按需——有 Source/Target 的事件传 Source+Target；`AttributeChangedEvent` 本身已携带 Target，只传 payload。

### SG 输出 3：Payload 读取辅助（可选）

```csharp
public sealed partial class GameplayEventFrame
{
    public ref DamageEvent GetDamagePayload(int index)
        => ref DamageEvents.GetRef(index);

    public ref AttributeChangedEvent GetAttributeChangedPayload(int index)
        => ref AttributeChangedEvents.GetRef(index);
}
```

## 数据流

```
AttributeAggregatorManager.Flush()
  │
  ├─ Evaluate → 写回 CurrentValue
  ├─ 发现 changed: OldValue ≠ NewValue
  └─ eventBus.Enqueue(new AttributeChangedEvent {
         Target = entity,
         Attribute = attr,
         OldValue = old,
         NewValue = result,
     });
     → pending.AttributeChangedEvents.Add(payload) → index=2
     → pending.Records.Add(record { EventId=Attribute, PayloadIndex=2 })

下一帧 Phase 0:
  GameplayEventDispatcher.Tick()
    → bus.Swap() → current = 刚填满的帧
    → 遍历 current.Records
    → record.EventId = Attribute, PayloadIndex = 2
    → 分发到 static handlers + dynamic listeners
    → handler 通过 frame.GetAttributeChangedPayload(2) 读取完整数据
```

## 与现有逻辑的兼容性

- `WaitGameplayEventTask` —— 只比较 `record.EventId`，不依赖 payload。`EventId` 不变，PayloadIndex 填充不影响它。
- `StructBuffer<T>` —— 已是泛型，不需要改动。`GameplayEventRecord` 作为 Records buffer 保持不变。
- `GameplayEventDispatcher.Tick()` —— 分发逻辑不变，handler 内部自己决定是否读取 payload。

## 本次不做

- 网络传输 / Serializer（ReadXxxEvent / WriteXxxEvent）
- `GameplayEventRegistry` 的 PayloadSize 扩展
- 动态 Listener 的 InvokeTable 类型化 dispatch
